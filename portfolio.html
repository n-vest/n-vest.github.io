Data Infrastructure
PEAK Literacy

Building an integrated data system for literacy programming and evaluation.

PEAK Literacy serves students across community and school-based sites, generating data across enrollment, tutoring, assessment, attendance, and reading progress. I am designing the data infrastructure that connects these sources into a coherent system for program operations, evaluation, and decision-making.

System Architecture
Intake → CRM → Assessments + Great Leaps → Analysis → Reporting
01

Relational data system

Designed a relational CRM architecture connecting students, caregivers, tutors, program sites, assessments, and operational records while reducing duplicate and disconnected data.

02

Automated data pipelines

Built workflows connecting enrollment and program forms, CRM records, Great Leaps data, and assessment results, reducing manual entry and surfacing data-quality problems.

03

Assessment automation

Developed automated scoring and data workflows for literacy assessments, including TOWRE-2 and fluency measures, so results can flow directly into longitudinal student records.

04

Analytics & reporting

Developing longitudinal datasets and reporting infrastructure that integrate attendance, reading progress, assessments, and student characteristics to support program evaluation and operational decisions.
